# Studio 5000 Logix Designer Source Protection Reference

This repository serves as a reference hub for control engineers, automation programmers, and system integrators seeking solutions to manage or recover password-based Source Code Protection configurations within Rockwell Automation software environments. 

## Technical Demonstration

For a practical demonstration showing how to work with locked routines, grayed-out subroutines, and missing `sk.dat` files across modern revisions, see the link below:

* **Watch the Walkthrough:** [Allen Bradley Studio 5000 Logix Designer Source Protection Service](https://youtu.be/AYBnhboPK7Y?si=iUm78cqlnGVSehc0)

## Supported Environment Details


* Allen Bradley Studio 5000 Logix Designer (Versions 30 through the latest V38 releases)
* Legacy RSLogix 5000 Platforms (Version 20 and later)
* Standard project components including `.ACD` file logic packages
